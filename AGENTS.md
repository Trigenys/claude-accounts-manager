# Engineering contract

This repository is generated by Trigenys AppFactory.

## Rules

- Keep privileged filesystem and operating-system access behind narrow Rust commands.
- Treat user files as untrusted input; parsers must be bounded and non-executing.
- Never commit credentials, tokens, private keys or user data.
- Add tests for behavior changes and regression fixes.
- Link implementation pull requests to the relevant GitHub Issue.
- Keep Project Automation configuration intact unless the platform contract is intentionally being upgraded.

## Product rules

- The app reads only quota and usage data exposed by Claude Code; it never reads, stores or transmits login tokens or credentials.
- Usage alert and reset notification logic lives in `src-tauri/src/usage_alerts.rs` and `reset_notify.rs`; keep its unit tests green.
- Do not launch the dev app from a terminal embedded in Claude Desktop (MSIX package): see `docs/engineering/lessons-learned.md`.
