Confidentialité

Vos jetons de connexion restent où ils sont.

Les quotas sont demandés à Claude Code lui-même, comme la commande /usage. Aucun message n'est envoyé à un modèle, rien n'est consommé.

Jamais

  • Lire, stocker ou transmettre un jeton de connexion
  • Envoyer vos données à un serveur, Trigenys compris
  • Modifier votre profil principal ~/.claude

Seulement, et en local

  • Les pourcentages de quota renvoyés par Claude Code
  • La consommation de tokens des journaux de session
  • Le forfait et l'email du profil, jamais un secret

Avant d'installer, en toute franchise.

  1. Windows 10 ou 11, 64 bits

    Un installeur de 2 Mo, sans droits administrateur. Pas encore de version macOS ni Linux.

  2. SmartScreen va vous prévenir

    L'installeur n'est pas encore signé. Cliquez sur Informations complémentaires, puis Exécuter quand même.

  3. Claude Code requis

    L'app lit les quotas que Claude Code expose. Installez-le et connectez chaque compte une fois.
